# 🦌 宿舍小程序

> 宿舍 6 人专用回寝登记 + 抽签 + 朋友圈 + 吃饭询问小程序

[![WeChat Mini Program](https://img.shields.io/badge/WeChat-Mini%20Program-1AAD19)]()
[![CloudBase](https://img.shields.io/badge/Tencent-CloudBase-00A4FF)]()

一个为宿舍场景设计的微信小程序，包含四个核心功能：

1. **回寝登记**：每人每天登记「预计回寝时间」（时间选择器），公开给全宿舍。
2. **自律抽签**：宿舍成员每日一签，看看今天是「鹿」还是「不鹿」。
3. **宿舍空间**：朋友圈式动态，发文字+图片（最多 9 图）、点赞、评论。
4. **吃饭询问**：一键发起「中午/下午吃什么？」，全宿舍投票（不知道/泡面/已经点了外卖/南门/食堂）。

---

## ✨ 功能特性

### 🏠 回寝登记（预计回寝时间）
- 时间选择器登记你预计回宿舍的时间（不是打卡当时的时间）
- 随时可以修改自己的预计时间
- 今日宿舍预计回寝一览（按时间排序，最早/最晚标记）
- 历史 7 天登记日历
- 个人登记数据统计（连续天数、最长连签、登记率）

### 🎋 自律抽签
- 每日一签（每人每天只能抽一次）
- 50% 概率抽到「鹿」或「不鹿」
- 摇晃动画仪式满满
- 抽签结果弹层揭示
- 今日签运分布柱状图
- 个人抽签历史（含鹿运指数）

### 🛋️ 宿舍空间（朋友圈）
- 发布动态：文字 + 最多 9 张图片
- 图片上传阿里云 OSS，永久保存（https 公共读地址，宿舍任何人都能看）
- 时间线展示，相对时间显示（刚刚/x分钟前/昨天）
- 点赞 / 取消点赞（云函数维护，所有人可见）
- 评论（所有人可见）：支持**内置表情面板**和**带一张图片**，图片同样存 OSS
- 删除自己的动态（连带评论和图片一起清理）

### 🍚 吃饭询问
- 首页一键发起「中午/下午吃什么？」询问
- 固定 5 个选项：不知道 / 泡面 / 已经点了外卖 / 南门 / 食堂
- 全宿舍都能作答，可随时改自己的答案
- 实时汇总：每个选项几人选、分别是谁
- **可转发到宿舍群**：群里点卡片直接进入作答页（零配置，开箱可用）
- **可开启微信提醒**：发起时给室友推「服务通知」（一次性订阅，需在小程序后台申请模板，见 [docs/吃饭提醒配置.md](docs/吃饭提醒配置.md)）

### 📚 作业共享
- 首页「作业共享」进入，宿舍内部的作业中转站
- 分享时手写**作业名字**（最多 30 字），再选文件
- 支持**图片**（相册/拍照）和 **Word / PDF / PPT / Excel / Markdown / TXT / 压缩包** 等格式
- 单文件上限 20MB，文件存阿里云 OSS，永久可访问
- 点击直接打开：图片放大预览、文档用 `wx.openDocument` 打开、Markdown/TXT 直接显示内容
- 下拉刷新

### 👤 个人中心
- 一键获取微信头像昵称
- 可随时修改昵称
- 打卡 + 抽签综合数据看板
- 7 天打卡率进度条

## 🚀 部署指南

### 1️⃣ 准备工作

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册小程序账号（个人/企业均可），获取 **AppID**
3. 注册腾讯云账号，开通 [云开发 CloudBase](https://console.cloud.tencent.com/tcb)（每个账号可创建 1 个免费环境）

### 2️⃣ 导入项目

1. 打开微信开发者工具
2. 选择「导入项目」
3. 项目目录：选择本仓库 `luguan-dorm/miniprogram` 目录
4. AppID：填入你自己的 AppID
5. 项目名称：宿舍（或自定义）

### 3️⃣ 配置云开发环境

1. 在微信开发者工具中点击工具栏「云开发」按钮
2. 选择「创建新环境」（建议选包年套餐，6 人宿舍用量免费额度足够）
3. 复制你的 **环境 ID**（形如 `luguan-dorm-env-xxxxxx`）
4. 打开 `miniprogram/app.js`，找到 `env: 'luguan-dorm-env'` 这一行，改为：

```javascript
wx.cloud.init({
  env: 'luguan-dorm-env-xxxxxx', // ← 替换为你的环境 ID
  traceUser: true,
})
```

### 4️⃣ 部署云函数

在微信开发者工具左侧文件树，**右键云函数文件夹** → 「上传并部署：云端安装依赖」，共 6 个：

- `cloudfunctions/dbInit`
- `cloudfunctions/getOpenId`
- `cloudfunctions/saveUserInfo`
- `cloudfunctions/momentActions`
- `cloudfunctions/mealActions`
- `cloudfunctions/ossSign` ← 图片存储用，见下方「图片存储配置」

**对 `dbInit` 函数**：上传后，进入函数详情页 → 「云端测试」→ 传入空参数 `{}` → 点击「运行测试」，会自动创建 6 个数据库集合（`users`、`checkins`、`lottery`、`moments`、`comments`、`mealAsks`）。

### 5️⃣ 配置数据库权限

⚠️ **必须配置！** 否则数据无法读写。

在云开发控制台的「数据库」页面，分别对以下 6 个集合设置权限：

| 集合名 | 推荐权限 | 说明 |
|--------|---------|------|
| `users` | **所有用户可读，仅创建者可读写** | 所有人能看到彼此昵称头像 |
| `checkins` | **所有用户可读，仅创建者可读写** | 所有人能看到彼此预计回寝时间 |
| `lottery` | **所有用户可读，仅创建者可读写** | 所有人能看到彼此抽签 |
| `moments` | **所有用户可读，仅创建者可读写** | 所有人能看到动态，点赞走云函数 |
| `comments` | **所有用户可读，仅创建者可读写** | 所有人能看到评论 |
| `mealAsks` | **所有用户可读，仅创建者可读写** | 所有人能看到吃饭询问，作答走云函数 |

具体操作：
1. 点击集合名 → 进入集合详情
2. 切换到「权限设置」tab
3. 选择「所有用户可读，仅创建者可读写」

> 💡 点赞/吃饭作答之所以走云函数：前端 SDK 无权修改别人的动态文档（likes / answers 字段），云端有管理员权限可以。

### 5️⃣➕ 图片存储：改用阿里云 OSS（必做！否则别人看不到头像和动态图片）

**为什么不用云开发自带的云存储？**
微信云开发的**免费体验环境**（6 个月，小程序上线后 15 天到期）存在功能限制：
云存储的权限被锁死在「仅创建者可读写」，控制台里选不了「所有用户可读」。
结果就是——你自己能看到自己的头像和照片，**室友看到的全是裂图**（文字、点赞、打卡都正常）。

所以本项目的头像和动态图片改存 **阿里云 OSS**（数据库和云函数仍在微信云开发，只换存储这一层）。
费用大约 10~30 元/年，比云开发转付费 19.9 元/月划算得多。

👉 **完整配置步骤见 [docs/阿里云OSS接入指南.md](docs/阿里云OSS接入指南.md)**

速览（4 步）：

1. 阿里云建 Bucket，读写权限选 **「公共读」**，记下地域（如 `oss-cn-hangzhou`）
2. 建 RAM 子账号拿 AccessKey，只授权该 Bucket 的 `PutObject` / `GetObject`
3. 小程序后台 → 开发设置 → 服务器域名 → **uploadFile 合法域名**填 `https://你的bucket.oss-cn-xxx.aliyuncs.com`
4. 填 `cloudfunctions/ossSign/config.js`（或配环境变量），上传部署 `ossSign`，超时时间改 60 秒

> 💡 上传走「服务端签名 + 前端直传」：AccessKey 只存在云函数里，小程序包里没有密钥。
> 旧动态里的 `cloud://` 图片可以执行一次 `{"action":"migrate"}` 迁移到 OSS，详见指南第 6 节。

### 6️⃣ 真机预览

1. 在微信开发者工具中点击「预览」
2. 微信扫码，即可在手机上体验
3. **6 个人都扫码即可共享数据**

## 🎯 使用说明

### 首次进入
- 弹窗要求设置昵称和头像
- 微信授权获取昵称和头像，或手动输入

### 回寝登记
- 点击「回寝登记」tab → 点击大圆按钮弹出时间选择器
- 选择你**预计回宿舍的时间**并保存（可随时修改）
- 所有人都能在列表里看到彼此的预计回寝时间
- 可在「我的记录」查看最近 7 天登记情况

### 吃饭询问
- 首页点击「吃饭询问」卡片
- 切换「中午 / 下午」tab → 没有询问时点「发起询问」
- 所有人点选项作答（不知道/泡面/已经点了外卖/南门/食堂），可改答案
- 实时显示每项几人选、谁选了什么

### 抽签
- 点击「自律抽签」tab → 点击签筒
- 等待 2.5 秒动画结束
- 弹出结果弹层，显示「鹿」或「不鹿」
- 每人每天只能抽一次

### 邀请室友
- 在「抽签」页点击右上角「···」→「转发」给室友
- 或者直接分享小程序码让室友扫码加入

## 🗄️ 数据库结构

### users 集合
| 字段 | 类型 | 说明 |
|------|------|------|
| `_openid` | string | 系统字段，微信 openid |
| `nickname` | string | 昵称 |
| `avatarUrl` | string | 头像 URL |
| `createdAt` | date | 创建时间 |
| `updatedAt` | date | 更新时间 |

### checkins 集合
| 字段 | 类型 | 说明 |
|------|------|------|
| `_openid` | string | 系统字段 |
| `nickname` | string | 冗余：方便查询 |
| `avatarUrl` | string | 冗余：方便查询 |
| `date` | string | YYYY-MM-DD |
| `submittedAt` | date | 登记提交时间 |
| `hour` | number | 预计回寝小时 0-23 |
| `minute` | number | 预计回寝分钟 0-59 |

### lottery 集合
| 字段 | 类型 | 说明 |
|------|------|------|
| `_openid` | string | 系统字段 |
| `nickname` | string | 冗余 |
| `avatarUrl` | string | 冗余 |
| `date` | string | YYYY-MM-DD |
| `result` | string | "鹿" 或 "不鹿" |
| `timestamp` | date | 抽签时间 |

## 🔧 自定义扩展

### 修改「宿舍总人数」
默认 6 人。如需调整，修改 `pages/index/index.js`：
```javascript
totalMembers: 6,  // 改为你的宿舍人数
```

### 修改抽签概率
`pages/lottery/lottery.js` 第 110 行附近：
```javascript
const result = Math.random() < 0.5 ? '鹿' : '不鹿'
// 改为 < 0.6 即鹿的概率为 60%
```

### 添加更多签种
把 `result` 字段改为数组或字符串：
```javascript
const results = ['鹿', '不鹿', '大吉', '小吉']
const result = results[Math.floor(Math.random() * results.length)]
```
记得同步修改 `pages/lottery/lottery.wxml` 中的展示逻辑。

## ❓ 常见问题

### Q1：6 个人怎么互相看到？
答：每个人打开小程序都用同一个云开发环境（env id 相同），所以数据共享。无需任何配置。

### Q2：每个人用同一个微信号还是不同微信号？
答：必须不同微信号。系统通过 `_openid` 区分用户，这是每个微信号唯一的。

### Q3：抽签结果能改吗？
答：不能。抽签后立即写入数据库，无法修改，保证公平。

### Q4：打卡有时间限制吗？
答：没有。理论上 24 小时都能写随时打卡（应用时长或凌晨 0 点后算新一天）。

### Q5：能加新功能吗？
答：可以！本项目完全开源可改。常见扩展：
- 打卡排行周榜/月榜
- 抽签仪式感升级（多签筒、抽签动画）
- 宿舍排行榜（最勤奋宿舍员）
- 抽奖箱（自定义签种）

### Q6：为什么室友看不到我的头像和照片？
答：免费云开发环境的云存储权限被锁成「仅创建者可读写」，别人读不了你的文件。
本项目已把图片存储切到阿里云 OSS 来解决，按 [docs/阿里云OSS接入指南.md](docs/阿里云OSS接入指南.md) 配置即可。
如果已经配好 OSS 但老照片还是不显示，执行一次迁移：`{"action":"migrate"}`（指南第 6 节）。

### Q7：想和室友一起开发，怎么协作？
答：见 [docs/协作开发指南.md](docs/协作开发指南.md)，Git 命令速查见 [docs/Git常用指令.md](docs/Git常用指令.md)。

核心四条：
1. 小程序后台「成员管理」把室友加为开发者（不加就编译不了）
2. 代码走 GitHub 私有仓库 + 分支 + PR
3. **云函数只由一个人统一部署**（否则互相覆盖）
4. **数据库是共享的**，测试数据其他人都能看到，改结构前先打招呼

### Q8：转云开发付费套餐是不是也能解决？
答：能。基础套餐 19.9 元/月（≈239 元/年），转付费后就能在控制台把云存储权限改成「所有用户可读」，
代码不用动。相比之下 OSS 一年只要 10~30 元，但要按指南配一次。两条路都行，自己权衡。
